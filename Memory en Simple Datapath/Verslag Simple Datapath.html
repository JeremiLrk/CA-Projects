Verslag

Program Counter

Als eerste opdracht moesten we een program counter maken.

Voor onze program counter hebben we de gegeven inputs en outputs gebruikt, namelijk 2 adders en 1 12-bit register.

De PC (program counter) telt elke keer met 1 op. Dit kan veranderen door de branch relative of branch absolute. Als de branch relative input op 1 staat wordt er niet meer met 1 opgetelt maar er wordt opgeteld met de branch value zelf (in de 2's complement waarde). Als de branch absolute op 1 staat, dan wordt de output (instruction adress) meteen op de branch value zelf gezet.

Dit hebben we kunnen implementeren door gebruik te maken van multiplexers zodat de output overeenkomt met de inputs.




Decoder

Als tweede opdracht hebben we een Decoder gemaakt.

Onze decoder hebben we gebouwd met de gegeven inputs en outputs en verschillende comparators. We keken naar de tabel uit de opgave en stelden een soort van 'if-conditions' op, die we dan implementeerden door gebruik te maken van comparators. Bijvoorbeeld als de 12-,13-,14- en 15-de (samen) bit groter is dan 0001 en kleiner dan 1010 dan is er een waarde voor rt. Zo hebben we dit gedaan voor alle outputs.




Controller

Als derde opdracht hebben we een controller gemaakt.

De inputs zijn zoals in de opgave gegeven, de operation code en de function code.

Voor de outputs hebben we de:

- ALUop : Deze is de ALU-code, die ervoor zorgt dat de juiste bewerking wordt gedaan. Dit hebben we gedaan door elke operatie te maken en te verbinden met de juiste delen van de output.

- ALUsrc : Deze kiest of we de immediate of T als tweede output pakken bij de ALU. De ALUsrc kan enkel aan gaan als er een immediate is, dus hebben we alle operations die immediate bevatten door een OR-gate verbonden met de output.

- MemToReg: Selecteert gegevens om naar de register file te sturen om te schrijven. We doen dit door de operatie LW te verbinden met de output.

- MemRead: Vertelt het geheugen om te lezen. We doen dit door de operatie LW te verbinden met de output.

- MemWrite : Vertelt het geheugen om een schrijfactie uit te voeren. We doen dit door de operatie SW te verbinden met de output.

Datapath

Met al onze bouwstenen (ALU, register file, PC, RAM-blokjes, Decoder en controller) kunnen we nu ons Datapath opstellen. We plaatsen eerst onze PC die we verbinden met het eerste RAM-blokje, dat we op de juiste instellingen hebben gezet die hier nodig zijn. We verbonden dan al alle mogelijke verbindingen zoals de reset en klok en bij de PC ook constanten voor de branch relative/absolute. Daarna plaatsten we onze decoder, controller en Register file die wij dan ook telkens verbonden met elkaar. Hierna plaatsten we de ALU en het tweede RAM-blokje. We gebruiken multiplexers om er zeker van te zijn dat de ALU de juiste input krijgt (Bij één van de multiplexers wordt gebruik gemaakt van de ALUsrc). De ALUop output is natuurlijk de operation code van de ALU. De output van de ALU gaat dan vervolgens in maar ook naast het RAM-blokje. Deze twee delen van de ALU output (het deel rechtstreeks uit de ALU en het deel dat uit het RAM-blokje komt) steken we dan in een multiplexer die beslist welke van de twee wordt gekozen. De input om de keuze te maken is de MemToReg. De output van deze laatste multiplexer gaat dan natuurlijk in de Data input van de register file.

In ons datapath zijn er ook twee comparators te vinden. Deze zijn gebruikt om enkele problemen op te lossen, die tijdens het testen van het Datapath, werden gevonden.
