Verslag

Oefening 1

Voor de eerste oefening hebben we een 12-bit register gemaakt.

Om een 12-bits register te bouwen met D flip-flops, hebben we de flip-flops op falling edge gezet. De reset zorgt ervoor dat alle flip-flops op nul gezet worden wanneer dit signaal actief is. De write control laat toe om data op te slaan als dit signaal hoog is.

Vervolgens hebben we alles verbonden op de plaats waar het hoort.




Oefening 2

Voor de tweede oefening moesten we een register file maken.

Hierbij hebben we gebruik gemaakt van de gegeven inputs uit de opgave, de gegeven outputs, een decoder voor de rd input te bepalen, 8 12-bit registers en 2 multiplexers die als hun operatiecode rs en rt hebben. De eerste multiplexer, met als operatiecode rs, is verbonden met de output S en de andere heeft als operatiecode de input rt met als output T.

Bij het allereerste 12-bit register zijn de data input en de write input 0. Daarna verbinden we de data input met alle andere 12-bit registers. Hetzelfde deden we met de reset. Voor de write input van de 12-bit registers gebruiken we een AND-gate waarvan 1 input de write input is en de anderen een input van de decoder.

De outputs van de 12-bit registers gaan in beide multiplexers op hun plaats. De multiplexers hebben, zoals eerder vermeld, de operatie codes rs en rt en als output respectievelijk S en T.




Oefening 3

Voor de derde oefening moesten we een counter maken.

Om onze counter te bouwen, hebben we gebruik gemaakt van volgende bouwblokken: onze 12-bit CLA uit het project van adders en onze 12-bit register. We hebben ook nog gebruik gemaakt van een comparator zodat we kunnen aangeven wanneer deze moet (stoppen met) optellen.

De inputs zijn een 12-bit input, waaraan we de waarde geven tot welke de counter moet tellen en eveneens de klok. De output is natuurlijk de teller die aangeeft tot hoeveel er geteld is op dat moment.

De counter werkt door telkens 1 op te tellen bij de vorige waarde.




Oefening 4

Voor de vierde oefening moesten we een traffic light maken door gebruik te maken van onze counter.

We zijn begonnen door de counter een input 01c te geven. Dit zorgt ervoor dat de counter zal tellen tot 28 seconden en dan terug opnieuw zal beginnen. Dan hebben we comparators gebruikt om een soort 'conditions' (vergelijkbaar met if-statements in programmeertaal) te maken voor de counter. De waarde waarmee vergelijkt wordt, zijn waarden die op de grenzen liggen waarbij er van kleur wordt veranderd in de opdracht. Door nog een beetje logica te gebruiken hebben we de outputs van de comparator verbonden met de lichten zodat het overeenkomt met de 'tijdlijn' uit de opgave. De lichten hebben we ook nog een kleur gegeven (rood,oranje en groen).
